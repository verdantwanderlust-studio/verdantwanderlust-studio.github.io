給 Ivy · 更新網站指南

說一句話,就更新網站

三種方式,由簡到進階。先看「方式一」 —— 那個一定能用。

00你要改的檔案在哪

網站的文字都整理成乾淨的小檔案了,放在這幾個地方:

檔案對應頁面你會改的
pages/about.yaml關於我自我介紹文字
pages/courses.yaml課程課名、介紹、時間地點費用
pages/contact.yaml聯繫Email、電話、地址

它們長這樣 —— 只改引號裡的中文字,其他符號不要動:

title: "關於我"
lede: "巴掌大的玻璃裡,裝著一整座會自己呼吸的森林。"

01網頁直接改一定能用

最穩。只要你會登入 GitHub 就行,不用裝任何東西。

  1. 用瀏覽器打開要改的檔案(關於頁的網址):
    github.com/verdantwanderlust-studio/verdantwanderlust-studio.github.io/blob/main/src/content/pages/about.yaml
  2. 點右上角的鉛筆圖示(Edit)
  3. 改引號裡的中文字(引號、冒號、縮排都別動)
  4. 拉到最下面,點綠色的 Commit changes
  5. 等 3–5 分鐘,網站自動更新
怕改錯改之前先把原本的字複製貼到記事本,改壞了可以貼回來。

02在 Claude 裡對話改進階

設好之後,你在 Claude Desktop 打字說「幫我把關於頁改成 ⋯⋯」,它就自動幫你改 + 上線。

先決條件:Claude Desktop app(Pro 或 Max 方案);一個能存取那個專案的 GitHub 帳號。

第一步 — 建一把「鑰匙」(只做一次,約 5 分鐘)

  1. 打開 github.com/settings/personal-access-tokens/new
  2. Token name:打「Claude 更新網站」
  3. Expiration:選 90 天
  4. Repository access:選 Only select repositories,勾選 verdantwanderlust-studio.github.io
  5. Permissions 只改這兩項:
    • Contents → Read and write
    • Metadata → Read-only(通常自動勾上)
  6. 點 Generate token
  7. 把那串 github_pat_… 複製起來,貼到記事本暫存

第二步 — 在 Claude Desktop 加 connector

  1. 開 Claude Desktop → 頭像 → Settings → Connectors
  2. 點 Add custom connector
  3. URL 貼:https://api.githubcopilot.com/mcp/
  4. 照畫面用 GitHub 登入授權(或貼上第一步的鑰匙)
  5. 完成後重開 Claude Desktop

第三步 — 測試

幫我看一下 verdant 那個專案,about.yaml 現在的內容是什麼?

讀得到就成功。再試「幫我把 lede 改成 ⋯⋯,然後 commit 到 main」。

如果第二步說「無法連線 / not available」代表你的 GitHub 帳號還沒被開通這功能(目前限量中)。別卡在這 —— 直接用方式一一樣能更新。想要對話式的話,把這份的「方式三」轉給 Jason。

03本機 server給 Jason

這段給工程師看 · Ivy 不用懂remote connector 還在限量,要保證 Ivy 能用對話式,改掛 local GitHub MCP server。

Claude Desktop 設定檔(macOS):
~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@github/github-mcp-server@latest"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "github_pat_在這裡貼上"
      }
    }
  }
}
  • 需要機器有 Node.js(npx)
  • token 用同一把 fine-grained PAT(限該 repo、Contents 讀寫)
  • 存好後重開,Settings → Connectors 應看到 github 已啟用
  • 這條不靠限量 rollout、保證可用,代價是編一次 JSON + 裝 Node

重點提醒

  • 不論哪種方式,Pages 都會在 push 後 3–5 分鐘自動上線,你不用做別的。
  • 改 YAML 只動引號裡的中文,符號別碰。
  • 不確定有沒有成功 → 問 Claude「有上線嗎」,或開網站重整看看。
  • 真的卡住 → 找 Jason,不丟臉。
